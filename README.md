# Админка клуба — бэкенд для Gizmo

Небольшой сервер на Python (без дополнительных пакетов). Стоит рядом с Gizmo
и отдаёт телефону приложение и только разрешённые команды.

## Запуск

1. Распакуйте папку, например в `C:\club-admin`.
2. Дважды кликните `start.bat`. При первом запуске создастся `.env` из `.env.example`.
3. В окне появятся адреса. С телефона откройте адрес с пометкой `(Tailscale)`
   (или адрес в той же Wi-Fi), например `http://100.x.x.x:8787`.
4. Войдите логином и паролем оператора Gizmo.

Windows при первом запуске может спросить про брандмауэр — разрешите доступ
для частных сетей.

## Приложение на телефоне (айфон и андроид)

Чтобы поставить приложение на главный экран, телефону нужен адрес `https://`.
Его бесплатно даёт Tailscale:

1. Откройте https://login.tailscale.com/admin/dns и включите **MagicDNS**
   и **HTTPS Certificates** (один раз).
2. На ПК с сервером в терминале выполните:
   ```
   tailscale serve --bg 8787
   ```
   Tailscale покажет адрес вида `https://desktop-xxxx.имя-сети.ts.net`.
   Команда запоминается и работает после перезагрузки ПК.
3. На телефоне включите Tailscale и откройте этот адрес.
   - **Айфон:** только в Safari → «Поделиться» → «На экран „Домой“».
   - **Андроид:** Chrome → меню ⋮ → «Установить приложение»
     (или кнопка «Установить» в разделе «Настройки» приложения).

Появится иконка «Админка», приложение открывается без адресной строки.
Обновления приходят сами: достаточно заменить файлы на сервере.

## Что умеет

| Раздел | Что делает | Как через Gizmo |
|---|---|---|
| Вход | проверка логина/пароля оператора | Basic-авторизация Web API |
| Зал | ПК: свободен / занят / не в сети / включается | hostcomputers + активные сессии + отклик клиента |
| ПК | перезагрузить, выключить (через 15 с) | запуск `shutdown.exe` на ПК |
| ПК | включить | Wake-on-LAN по MAC из Gizmo |
| ПК | сообщение на экран | запуск `msg.exe` на ПК |
| Диспетчер задач | программы пользователя с иконками и ЦП, завершить | процессы ПК, завершение деревом |
| Склад | сверка факта с остатками Gizmo, акт, CSV | только чтение остатков |
| Смена | статус, касса, оператор, сумма | отчёт по сменам (только чтение) |

Защищено: системные процессы и клиент Gizmo завершить нельзя; остатки и смену
приложение не меняет; 5 неверных паролей — пауза 5 минут; пароль оператора
хранится только в памяти сервера на время сессии.

Все действия пишутся в `actions.log` (кто, что, на каком ПК, когда).

## Что ещё проверить на втором ПК

- Перезагрузка/выключение (на ПК с сервером не запускайте!).
- Wake-on-LAN: в BIOS ПК должен быть включён Wake on LAN, ПК — в той же сети.
- Сообщение: `msg.exe` есть в Windows Pro/Enterprise, в Home его может не быть.
